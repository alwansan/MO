## Best path determined
1. **Safest + lowest cost:** run existing `MO Graphics Probe v0.11.0-alpha.11` P13 read-only ANGLE capability scan on POCO and obtain its `Download/log.txt`, then decide if genuine system ANGLE per-app GL identity override is even plausible. No GPU Debug/global ANGLE setting toggles or root. This is not automatically a cross-app bypass.
2. **If willing to use a container for testing:** original lightweight App Virtualization architecture has greater theoretical control than a plain launcher and lower expected costs than an entire guest Android VM. Investigate BlackBox Reborn as a **reference** under license review, test a separate openly permitted 64-bit native GLES/Vulkan reader first, not a live Outlanders account; prove true app-internal GL/Java value before any gameplay claims. This is a research direction, not user consent to install/clone a protected game or evade its integrity checks.
3. **Full VM last:** GMS cannot automatically reuse signed-in host credentials; isolated account/services, performance and anti-cheat/PlayIntegrity risks; Microdroid unsuitable for graphics.
4. **Android/data edits not supported by this ZIP:** no visible editable GPU settings, binary hotfix/cache, uncertainty and EULA risk. Do not create fake patch PAKs or bypass rules.
5. **Official developer support request** for device whitelist provides a safer possible solution for the original installed game.
